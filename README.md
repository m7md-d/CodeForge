## 🧬 Architectural Overview
CodeForge Command Center is a comprehensive learning and task orchestration platform. It models curriculums through a strictly hierarchical Skill Tree: **Sprints** house **Projects**, and Projects map **Tasks**.

- **Vast Telemetry Matrix**: Tracks global execution status via dynamic Progress Bars and calculates hierarchical XP math based on Project-Level Skill Tags.
- **Frontend Stack**: Built on React 18, Vite, and TanStack Query to drive instantaneous, zero-latency client-side rendering.
- **Backend Stack**: Powered by FastAPI, SQLAlchemy, and SQLite. Processes heavy multi-dimensional nested bulk inputs rapidly.
- **Data Persistence**: Architected for containerized deployment, mapping native volumes securely out of the deployment container to persist the SQLite Schema natively across Docker lifetimes.

## 🔮 Core Features

### 1. CodeForge Glassmorphism Arabic (RTL)
The entire User Interface features a breathtaking design language built completely raw utilizing `backdrop-filter: blur`, deep neon gradients (Neon Green, Corporate Blue, Crimson Alert), and a unified Cairo/Inter dual language font-stack supporting native Arabic-RTL and Imperial rendering simultaneously.

### 2. True XP Mathematics
A specialized progression matrix tying base Task Integers (`Points`) to generalized fractional multipliers mapped at the Project tier (`skill_tags: { "C Programming": 0.5 }`).
*`total_xp = project_base_xp * skill_tags_ratio`*

### 3. Omni-Edit Interface
Powerful Glassmorphism Modals empowering users to surgically bypass standardized inputs, manipulating raw nested JSON arrays (Forbidden Functions, Compiler Flags, Skill Tag Ratios) instantly via cached TanStack Mutations. Eliminates Stale DOM loops.

### 4. Macro-Injection Engine
LLM-Pipeline enabled. You can copy-paste pure JSON payloads generated by AI completely bypassing manual UI inputs. The engine maps strings to Dual Translations [EN, AR], calculates nested arrays, constructs Sprints, allocates UUIDs, and fires atomic REST requests.

## 🚀 One-Click Installation
Execute the deployment via the following standard Open-Source workflow.

1. **Clone the Repository**
```bash
git clone https://github.com/m7md-d/CodeForge.git
cd codeforge
```

2. **Boot the Orchestrator**
```bash
docker compose up --build -d
```

3. **Establish Access**
- **CodeForge UI:** [http://localhost:5173](http://localhost:5173) (Served internally via Nginx Reverse-Proxy caching over Port 80)
- **FastAPI OpenAPI Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)

## 🛠 Usage
After deployment, the primary workflow consists of mapping a "Sprint".
1. **The Macro Approach**: Navigate to the Dashboard, configure the Macro Payload JSON Box, and inject a full course load generated by Large Language Models. (See `JSON_SCHEMA.md` for the Prompt template).
2. **The Artisan Approach**: Construct a new Sprint. Expand its matrix and map out Projects. Enter a Project and surgically establish granular Tasks, compiler constraints, and point values. Set the Project bounds via Omni-Edit mappings.
3. **Execution**: Mark tasks complete. Watch the global XP tree update. Track streaks and progress visually on the Dashboard.
